# 🛢️ تحليل سيناريوهات الموازنة العراقية وأسعار النفط وسعر الصرف

تطبيق **Streamlit** تفاعلي يحلّل أثر **أسعار النفط** و**تخفيض سعر صرف الدينار**
على الإيرادات والعجز والاحتياطيات، مع التركيز على **الفجوة بين السعر الموازي والرسمي**
والتضخم المستورد.

🔗 **النسخة المنشورة:** https://iraqbudgetapp-vodfqp88y2obwcpjkahi6u.streamlit.app/

## ✨ المزايا

| التبويب / الميزة | الوصف |
|---|---|
| 📡 أسعار النفط اللحظية | شريط مؤشرات علوي لحظي يعرض أسعار خام برنت وخام البصرة التصديري والتغير اليومي، مع بديل فوري في وضع عدم الاتصال |
| 🎯 سيناريوهات جاهزة (Presets) | سيناريوهات قياسية بنقرة واحدة: الوضع الراهن 2025، الموازنة الثلاثية 199 ترليون، صدمة النفط 2020، طفرة الطاقة، وسد فجوة الصرف |
| 📊 نظرة عامة | الرصيد والإيرادات والنفقات وفاتورة الرواتب والاحتياطي + **عداد مؤشر الاستقرار المالي (Gauge)** + **مخطط سانكي لتدفق أموال النفط والموازنة (Sankey Flow)** |
| ⚖️ مقارنة السيناريوهات | مقارنة سيناريوهين جنباً إلى جنب (المرجعي vs المقترح) مع بطاقات الفروقات (Delta) ورسم بياني مقارن وجدول تحليلي شامل |
| 🎲 محاكاة المخاطر (مونت كارلو) | نمذجة احتمالية عشوائية لتقلبات أسعار النفط (GBM) لآلاف المسارات، وحساب احتمالية العجز، ومخاطر هبوط الاحتياطي دون M0، وأقصى عجز مالي (Fiscal VaR 95%) |
| 🛢️ النفط وتكاليف الإنتاج | نمذجة دقيقة للإنتاج الكلي والاستهلاك المحلي، مع خصم سلة خام البصرة وكلف جولات التراخيص |
| 💱 تخفيض سعر الصرف | أثر رفع سعر الصرف على الإيراد النفطي بالدينار والرصيد مقارنةً بالسعر الرسمي الأساس |
| ↔️ الفجوة الموازية/الرسمية | حساب الفجوة ونسبتها، وأثر سدّها جزئياً/كلياً، ومقايضة الرصيد مقابل التضخم |
| 🔥 الحساسية المزدوجة | خريطة حرارية للرصيد عند كل تركيبة (نفط × صرف) |
| 📈 التضخم والاستيراد | تقدير تقريبي للتضخم المستورد وزيادة فاتورة الاستيراد |
| 📋 التقرير التنفيذي والسياسات | ملخص استدامة لصنّاع القرار، وتوليد توصيات إصلاحية مالية ونقدية ذكية مصنفة بالأولوية، مع دعم الطباعة المباشرة وحفظ PDF |
| 📅 البيانات الفعلية (CBI) | سلاسل رسمية من البنك المركزي (الاحتياطي، M0، التضخم، سعر الصرف، الموازنة) + **تحقق النموذج مقابل الواقع** عبر «سعر النفط الضمني» |
| 🗂️ البيانات والتصدير | الجداول الكاملة وتنزيل النتائج (Excel / CSV) |

> 🟢 **السيناريو الافتراضي «أحدث بيانات فعلية» يتجدد من النشرة الرسمية للبنك المركزي**.
> يستخدم أحدث شهر مكتمل للمؤشرات النقدية وآخر سنة مكتملة للإنفاق والواردات؛ وتبقى السيناريوهات التاريخية ثابتة.
> اختر سيناريو جاهزاً من أعلى الشريط الجانبي أو اضبط القيم بحرية. تحقّق النموذج: السعر الضمني المشتقّ من الإيراد
> الفعلي ≈ 82$ (2024) و71$ (2025)، وهو قريب جداً من متوسط أسعار التصدير الفعلية.

## 🧮 المنهجية (موجزة)

- **صافي الصادرات الحكومية** = (حجم الإنتاج الكلي − الاستهلاك المحلي للمصافي) × حصة الحكومة
- **السعر الصافي للبرميل** = سعر النفط − خصم خام البصرة − كلف جولات التراخيص
- **الإيراد النفطي (دينار)** = السعر الصافي × صافي الصادرات × أيام السنة × سعر الصرف
- **سعر تعادل الرواتب** = سعر النفط الأدنى لتغطية فاتورة الرواتب والتقاعد وشبكة الحماية
- **سعر تعادل الموازنة** = سعر النفط الذي يحقق التوازن المالي الكامل
- **الرصيد** = إجمالي الإيرادات − النفقات (إجمالي أو جاري)
- **العجز** يُموَّل جزئياً من البنك المركزي ⇐ يخفض الاحتياطي
- **الفائض** يُخصَّص جزء منه للاحتياطي
- **سدّ الفجوة**: رفع السعر الرسمي نحو الموازي بنسبة قابلة للتعديل
- **التضخم المستورد** ≈ حصة السلع المستوردة × معامل التمرير × نسبة تغيّر الصرف

> ⚠️ النتائج تقديرية لأغراض تحليل السيناريوهات وليست توقعات رسمية.

## 🔄 التحديث الآلي لبيانات البنك المركزي

يعمل المسار `.github/workflows/update-cbi-data.yml` كل 6 ساعات، عند الدقيقة 23
(03:23 و09:23 و15:23 و21:23 بتوقيت بغداد). ويمكن تشغيله يدويًا من
**Actions → Update CBI data → Run workflow**. يعمل أيضًا عند تعديل شيفرة المزامنة.

- يقرأ [صفحة النشرة الرسمية](https://cbi.iq/page/122) ويكتشف رابط Excel الحالي، بدل تثبيت اسم ملف يتغير مع الإصدارات.
- يتحقق من بصمة SHA-256 للمحتوى، بما في ذلك تعديل الملف على الرابط نفسه.
- يقرأ عناوين الفترات والوحدات وأسماء الجداول، ويختبر اكتمال المؤشرات ومعادلة الإيرادات ناقص الإنفاق وتكرار الفترات. يرفض الرجوع إلى إصدار يغطي فترة أقدم.
- يستبعد أعمدة التواريخ المستقبلية مع الاحتفاظ بتفاصيل الاستبعاد، دون تخمين تاريخ بديل. تغير البنية غير المدعوم أو البيانات الناقصة يوقف الاعتماد.
- ينشر جميع الجداول في ملف واحد `data/cbi_latest.json` عبر استبدال ذري، بعد اكتمال التحقق. تُحفظ آخر نسخة سليمة إذا فشل التنزيل أو التحقق.
- يحدث `data/cbi_status.json` عند كل فحص، حتى دون تغير البيانات. يرفع GitHub سجل الفحص والبيانات التي تغيرت فقط، ولا يرفع ملف Excel الخام.
- يعرض الموقع آخر فحص، وآخر فحص ناجح، وتاريخ اعتماد النسخة، وفترة البيانات. تُحدّث الذاكرة المؤقتة عند تغير الملفات، وتفحص الجلسات المفتوحة التغير كل دقيقة. يظهر تنبيه إذا فشل التحديث أو مضت 18 ساعة على آخر تحقق ناجح.

التوقيت مجدول وليس ضمانًا لحظيًا؛ قد تتأخر GitHub Actions، وتتوقف الجدولة في المستودعات العامة غير النشطة بعد 60 يومًا. خطوات الفحص تنشر سجلًا عند كل تشغيل. إذا تعذر الدفع بسبب حماية `main` أو صلاحيات Actions، يظهر الفشل في سجل التشغيل؛ لا يُستخدم دفع إجباري.

### الفترات والافتراضات

«أحدث بيانات فعلية» يستخدم الاحتياطي وM0 وسعر الصرف من أحدث فترة نقدية مكتملة.
الإنفاق الإجمالي والجاري يأتيان من آخر سنة مالية مكتملة، والواردات من آخر سنة مكتملة تتوفر قيمتها.
لا يتم ضرب إنفاق جزء من السنة للوصول إلى تقدير سنوي. بقية الافتراضات، ومنها النفط والإنتاج والإيرادات غير النفطية والرواتب والسعر الموازي، تبقى افتراضات قابلة للتعديل وليست أرقامًا تُستنتج من هذه النشرة.

الجداول السنوية تشمل السنوات المكتملة فقط. جدول الموازنة الشهرية **تراكمي منذ بداية السنة** وليس إنفاق كل شهر منفردًا.
ملفات CSV القديمة تبقى مرجعًا احتياطيًا عند غياب النسخة الآلية؛ ملف JSON هو المصدر المعتمد عند وجوده.

### التشغيل والاختبار محليًا

```bash
python sync_cbi_data.py                 # تنزيل وتحقق وتحديث ذري للنسخة
python -m unittest test_cbi_data -v      # اختبارات دون اتصال للمزامنة والحماية من البيانات الخاطئة
python test_engine.py                  # اختبارات الحسابات
```

للتصدير اليدوي إلى CSV من ملف محلي:

```bash
python extract_cbi_data.py "البيانات الشهرية.xlsx" --output output/cbi
```

الملفات المساعدة: `extract_cbi_data.py` للتحليل، و`sync_cbi_data.py` للمزامنة،
و`cbi_data.py` لقراءة النسخة وتوليد الافتراضات ذات الفترات المعلنة.
